O estudo de HTML permitiu compreender como são construídas as páginas web e como os seus conteúdos podem ser organizados. Durante a aprendizagem, conheci diferentes etiquetas utilizadas para criar títulos, parágrafos, imagens e ligações. Estes conhecimentos ajudaram-me a perceber a estrutura de um website.

A aprendizagem de CSS possibilitou melhorar a apresentação das páginas criadas com HTML. Com esta linguagem, aprendi a modificar cores, tamanhos de letras, margens, bordas e alinhamentos. A utilização conjunta destas duas linguagens constitui uma base importante para desenvolver páginas web simples e organizadas.
